DEVELOPER CONSOLE / INTEGRATION GUIDE

Connect your application

Send a server-side JSON request to Afyora and read the clinical decision-support result from the response. Choose your language to see a ready-to-adapt example.

Before you start: register an integration and store its bearer token as CLINICAL_AI_TOKEN in your backend secret manager. These examples send requests from a trusted backend, not from browser or mobile code.

Python

Requires Python 3 and requests. Set CLINICAL_AI_BASE_URL for your deployment.

import os
import requests

base_url = os.getenv("CLINICAL_AI_BASE_URL", "http://127.0.0.1:8001")
token = os.environ["CLINICAL_AI_TOKEN"]
response = requests.post(
    f"{base_url}/api/clinical-ai/analyze/",
    headers={"Authorization": f"Bearer {token}"},
    json={"symptoms": ["fever"], "vitals": {"temperature": 38.5}},
    timeout=45,
)
response.raise_for_status()
analysis = response.json()
print(analysis["supported_diagnosis"])

Node.js

Requires Node.js 18 or later. Use built-in fetch from a server process.

const baseUrl = process.env.CLINICAL_AI_BASE_URL ?? "http://127.0.0.1:8001";
const token = process.env.CLINICAL_AI_TOKEN;
if (!token) throw new Error("CLINICAL_AI_TOKEN is not configured");

const response = await fetch(`${baseUrl}/api/clinical-ai/analyze/`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${token}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    symptoms: ["fever"],
    vitals: { temperature: 38.5 },
  }),
  signal: AbortSignal.timeout(45_000),
});
const result = await response.json();
if (!response.ok) throw new Error(`API ${response.status}: ${JSON.stringify(result)}`);
console.log(result.supported_diagnosis);

Java

Requires Java 17 or later and uses the built-in HttpClient.

import java.net.URI;
import java.net.http.*;
import java.time.Duration;

public class ClinicalAiExample {
    public static void main(String[] args) throws Exception {
        String baseUrl = System.getenv().getOrDefault(
            "CLINICAL_AI_BASE_URL", "http://127.0.0.1:8001");
        String token = System.getenv("CLINICAL_AI_TOKEN");
        if (token == null || token.isBlank()) {
            throw new IllegalStateException("CLINICAL_AI_TOKEN is not configured");
        }
        String payload = """
            {"symptoms":["fever"],"vitals":{"temperature":38.5}}
            """;
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(baseUrl + "/api/clinical-ai/analyze/"))
            .timeout(Duration.ofSeconds(45))
            .header("Authorization", "Bearer " + token)
            .header("Content-Type", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(payload))
            .build();
        HttpResponse<String> response = HttpClient.newHttpClient().send(
            request, HttpResponse.BodyHandlers.ofString());
        if (response.statusCode() < 200 || response.statusCode() >= 300) {
            throw new IllegalStateException("API " + response.statusCode() + ": " + response.body());
        }
        System.out.println(response.body());
    }
}

Go

Uses Go's standard library.

package main

import (
    "bytes"
    "fmt"
    "io"
    "net/http"
    "os"
    "time"
)

func main() {
    baseURL := os.Getenv("CLINICAL_AI_BASE_URL")
    if baseURL == "" { baseURL = "http://127.0.0.1:8001" }
    token := os.Getenv("CLINICAL_AI_TOKEN")
    if token == "" { panic("CLINICAL_AI_TOKEN is not configured") }

    payload := []byte(`{"symptoms":["fever"],"vitals":{"temperature":38.5}}`)
    request, err := http.NewRequest(http.MethodPost,
        baseURL+"/api/clinical-ai/analyze/", bytes.NewReader(payload))
    if err != nil { panic(err) }
    request.Header.Set("Authorization", "Bearer "+token)
    request.Header.Set("Content-Type", "application/json")

    client := &http.Client{Timeout: 45 * time.Second}
    response, err := client.Do(request)
    if err != nil { panic(err) }
    defer response.Body.Close()
    body, err := io.ReadAll(response.Body)
    if err != nil { panic(err) }
    if response.StatusCode < 200 || response.StatusCode >= 300 {
        panic(fmt.Sprintf("API %d: %s", response.StatusCode, body))
    }
    fmt.Println(string(body))
}

The API returns a validated JSON response. Handle non-2xx status codes, keep patient data and credentials on trusted servers, and require qualified clinician review of every result.

DEVELOPER CONSOLE / THE TRIAGE DESK

The Triage Desk — Integration Reference

The Triage Desk exposes a REST API for the complete SATS triage workflow — encounter registration, multi-step agentic assessment, clinician approval gate, and reassessment flagging. Integrate this into any EHR, EMR, or clinical information system.

Authentication: all triage endpoints require an authenticated session (Cookie: sessionid=…) or an integration bearer token (Authorization: Bearer <token>). Approval endpoints additionally require the authenticated user to have a ClinicalRole of NURSE or DOCTOR.

Endpoint overview

MethodPathDescriptionRole required
POST/api/triage/encounters/Register a triage encounterAny authenticated user
GET/api/triage/encounters/{id}/Encounter detail + workflow statusAny authenticated user
POST/api/triage/encounters/{id}/assess/Run LangGraph triage agentAny authenticated user
POST/api/triage/encounters/{id}/reassess/Flag for reassessmentAny authenticated user
GET/api/triage/encounters/{id}/audit/Full immutable audit trailNURSE or DOCTOR
POST/api/triage/approvals/{id}/decide/Approve or reject a proposalNURSE or DOCTOR

Workflow

  1. Register encounter — POST /api/triage/encounters/
    Creates the patient encounter. Returns encounter_id.
  2. Run assessment — POST /api/triage/encounters/{id}/assess/
    LangGraph agent runs: vitals validation → deterministic SATS rules → AI advisory → priority proposal. Returns proposed_priority and approval_id.
  3. Clinician approval — POST /api/triage/approvals/{id}/decide/
    A nurse or doctor approves or rejects the proposal. Only on APPROVED does confirmed_priority reach the queue.
  4. Reassessment (optional) — POST /api/triage/encounters/{id}/reassess/
    Flag new observations without moving the patient's queue position. Invalidates any pending approval.

Code examples

Python — full triage workflow

Requires requests. Set TRIAGE_BASE_URL and CLINICAL_AI_TOKEN.

import os, time
import requests

BASE = os.getenv("TRIAGE_BASE_URL", "http://127.0.0.1:8001")
TOKEN = os.environ["CLINICAL_AI_TOKEN"]
HEADERS = {"Authorization": f"Bearer {TOKEN}", "Content-Type": "application/json"}

# ── 1. Register encounter ────────────────────────────────────────────────
enc = requests.post(f"{BASE}/api/triage/encounters/", headers=HEADERS, json={
    "age": 52,
    "is_pregnant": False,
    "symptoms": ["chest pain", "shortness of breath"],
    "vitals": {
        "heart_rate": 135,
        "respiratory_rate": 26,
        "oxygen_saturation": 91,
        "blood_pressure": "110/70",
        "temperature": 38.8,
    },
}, timeout=30)
enc.raise_for_status()
encounter_id = enc.json()["encounter_id"]
print(f"Encounter: {encounter_id}")

# ── 2. Run triage assessment ─────────────────────────────────────────────
assess = requests.post(
    f"{BASE}/api/triage/encounters/{encounter_id}/assess/",
    headers=HEADERS, json={}, timeout=60,
)
assess.raise_for_status()
result = assess.json()
priority    = result["proposed_priority"]   # RED | ORANGE | YELLOW | GREEN | NOT_ASSESSED
approval_id = result["approval_id"]
escalation  = result["immediate_escalation"]
print(f"Priority: {priority}  |  Immediate escalation: {escalation}")
print(f"Recommendation: {result['recommendation']}")

# If RED / immediate escalation — act NOW before software steps
if escalation:
    print("⚠ IMMEDIATE EMERGENCY — activate clinical emergency protocol NOW")

# ── 3. Clinician approval ────────────────────────────────────────────────
# Must be called with credentials of a user who has ClinicalRole NURSE or DOCTOR
decision = requests.post(
    f"{BASE}/api/triage/approvals/{approval_id}/decide/",
    headers=HEADERS, json={
        "decision": "APPROVED",
        "comments": "Assessed at bedside — priority confirmed.",
    }, timeout=30,
)
decision.raise_for_status()
print(f"Approval: {decision.json()['status']}")
print(f"Confirmed priority: {decision.json()['confirmed_priority']}")

# ── 4. Optional: flag reassessment ──────────────────────────────────────
flag = requests.post(
    f"{BASE}/api/triage/encounters/{encounter_id}/reassess/",
    headers=HEADERS, json={
        "reason": "Patient reports worsening dyspnoea",
        "new_symptoms": ["worsening dyspnoea"],
        "new_vitals": {"oxygen_saturation": 88},
    }, timeout=30,
)
flag.raise_for_status()
print(f"Reassessment flag: {flag.json()['flag_id']}  |  queue_unchanged: {flag.json()['queue_unchanged']}")

Node.js — full triage workflow

Node.js 18+ with built-in fetch. Run from a server process.

const BASE  = process.env.TRIAGE_BASE_URL ?? "http://127.0.0.1:8001";
const TOKEN = process.env.CLINICAL_AI_TOKEN;
if (!TOKEN) throw new Error("CLINICAL_AI_TOKEN not set");

const HEADERS = {
  Authorization: `Bearer ${TOKEN}`,
  "Content-Type": "application/json",
};

async function triageFetch(path, body) {
  const r = await fetch(`${BASE}${path}`, {
    method: body ? "POST" : "GET",
    headers: HEADERS,
    body: body ? JSON.stringify(body) : undefined,
    signal: AbortSignal.timeout(60_000),
  });
  const data = await r.json();
  if (!r.ok) throw new Error(`${r.status}: ${JSON.stringify(data)}`);
  return data;
}

// 1. Register encounter
const { encounter_id } = await triageFetch("/api/triage/encounters/", {
  age: 52,
  is_pregnant: false,
  symptoms: ["chest pain", "shortness of breath"],
  vitals: { heart_rate: 135, respiratory_rate: 26, oxygen_saturation: 91 },
});
console.log("Encounter:", encounter_id);

// 2. Run assessment
const result = await triageFetch(`/api/triage/encounters/${encounter_id}/assess/`, {});
console.log("Priority:", result.proposed_priority, "| Escalation:", result.immediate_escalation);
if (result.immediate_escalation) console.error("⚠ IMMEDIATE EMERGENCY");

// 3. Clinician approval (requires NURSE or DOCTOR role)
const approval = await triageFetch(`/api/triage/approvals/${result.approval_id}/decide/`, {
  decision: "APPROVED",
  comments: "Assessed at bedside — priority confirmed.",
});
console.log("Confirmed priority:", approval.confirmed_priority);

// 4. Optional: flag reassessment
const flag = await triageFetch(`/api/triage/encounters/${encounter_id}/reassess/`, {
  reason: "Patient reports worsening dyspnoea",
  new_symptoms: ["worsening dyspnoea"],
  new_vitals: { oxygen_saturation: 88 },
});
console.log("Reassessment flag:", flag.flag_id, "| queue_unchanged:", flag.queue_unchanged);

Go — full triage workflow

Uses Go's standard library. Set TRIAGE_BASE_URL and CLINICAL_AI_TOKEN.

package main

import (
    "bytes"; "encoding/json"; "fmt"; "io"; "net/http"; "os"; "time"
)

var (
    base   = envOr("TRIAGE_BASE_URL", "http://127.0.0.1:8001")
    token  = os.Getenv("CLINICAL_AI_TOKEN")
    client = &http.Client{Timeout: 60 * time.Second}
)

func triagePost(path string, body any) map[string]any {
    b, _ := json.Marshal(body)
    req, _ := http.NewRequest("POST", base+path, bytes.NewReader(b))
    req.Header.Set("Authorization", "Bearer "+token)
    req.Header.Set("Content-Type", "application/json")
    resp, err := client.Do(req)
    if err != nil { panic(err) }
    defer resp.Body.Close()
    raw, _ := io.ReadAll(resp.Body)
    var result map[string]any
    json.Unmarshal(raw, &result)
    return result
}

func envOr(key, def string) string {
    if v := os.Getenv(key); v != "" { return v }; return def
}

func main() {
    // 1. Register encounter
    enc := triagePost("/api/triage/encounters/", map[string]any{
        "age": 52, "is_pregnant": false,
        "symptoms": []string{"chest pain", "shortness of breath"},
        "vitals":   map[string]any{"heart_rate": 135, "oxygen_saturation": 91},
    })
    encounterID := enc["encounter_id"].(string)
    fmt.Println("Encounter:", encounterID)

    // 2. Run assessment
    result := triagePost("/api/triage/encounters/"+encounterID+"/assess/", map[string]any{})
    fmt.Println("Priority:", result["proposed_priority"], "| Escalation:", result["immediate_escalation"])

    // 3. Clinician approval
    approvalID := result["approval_id"].(string)
    approval := triagePost("/api/triage/approvals/"+approvalID+"/decide/", map[string]any{
        "decision": "APPROVED", "comments": "Bedside review — confirmed.",
    })
    fmt.Println("Confirmed priority:", approval["confirmed_priority"])
}

SATS priority levels

CodeLevelSATS categoryAction
REDImmediateP1Resuscitation — within seconds
ORANGEVery urgentP2Within 10 minutes
YELLOWUrgentP3Within 60 minutes
GREENStandardP4Within 240 minutes
NOT_ASSESSED——Insufficient vitals to assess; escalate manually

Integration safety requirements

  • Never auto-approve. The /decide/ endpoint must be called by a human with a NURSE or DOCTOR clinical role. Automated callers will receive 401 Unauthorized.
  • Treat RED immediately. When immediate_escalation: true, surface the recommendation to clinical staff immediately — do not wait for the software approval step.
  • No PII in encounter payloads. The API stores no name, MRN, national ID, or date of birth. Use your own system's reference ID in encounter_ref to correlate records.
  • Store tokens server-side. Never send integration tokens to browsers or mobile clients.
  • Idempotency keys. Supply a unique idempotency_key on each approval request to prevent duplicate submissions from retries.
  • Audit trail. Every action generates an immutable AuditEvent. Fetch the full trail at GET /api/triage/encounters/{id}/audit/ (NURSE/DOCTOR role required).
